#Название Django Project - Catalog
##Домашняя работа(Проект) с выводом заготовки домашней страницы и контактов на Bootstrap.
## Для запуска проекта необходимо выполнить следующие дейстивия.
   1 - pip install -r requirements.txt
   2 - python manage.py runserver
   
### Настройка базы данных и переменных окружения
1. Создайте в корне проекта файл `.env` на основе шаблона `.env.sample`.
2. Заполните в файле `.env` ваши личные данные для подключения к PostgreSQL (имя БД, пользователь, пароль).
3. Примените миграции: `python manage.py migrate`
4. Для наполнения базы тестовыми данными запустите кастомную команду: `python manage.py fill`
